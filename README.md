# City Temperature and Dead Internet Analysis

This repository contains two complementary data science projects:

1. City Temperature Analysis (Python)
   - File: `City_Temperature_Analysis.ipynb`
   - A Python-based Jupyter notebook for exploring and visualizing city temperature data.
   - Focuses on temperature trends and pattern analysis using Python data science tools.

2. Reddit Dead Internet Analysis (R)
   - File: `Reddit_Internet_Analysis.Rmd`
   - An R Markdown project analyzing synthetic Reddit comment data to distinguish bot activity from human behavior.
   - Uses variables such as account age, reply delay, average word length, and bot probability to identify patterns associated with automated accounts.
   - Data source: `reddit_dead_internet_analysis_2026.csv`

The repository therefore includes both a Python workflow and an R workflow, each focused on a different dataset and analytical question, while sharing the broader theme of data exploration and pattern detection.
